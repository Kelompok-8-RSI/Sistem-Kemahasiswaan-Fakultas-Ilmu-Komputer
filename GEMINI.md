# Instruksi untuk AI agent

Proyek ini dikerjakan bergiliran oleh empat anggota Kelompok 8 (Ammar, Amirah, Jasmine, Rasil) dengan bantuan AI agent.

1. Sebelum melakukan apa pun, baca seluruh `docs/ai/PROMPT.md` (aturan, sumber referensi, dan rencana task T01 sampai T18).
2. Baca `PROGRESS.md` untuk mengetahui task terakhir yang selesai dan task berikutnya.
3. Jika pengguna mengetik `lanjut` (atau `lanjut <nama>`), jalankan protokol pada `docs/ai/PROMPT.md` bagian 5 untuk task berikutnya.
4. Kerjakan satu task per sesi. Jangan menjalankan `git add`, `git commit`, `git push`, atau `git merge`. Berikan perintahnya kepada pengguna sesuai format di `docs/ai/PROMPT.md` bagian 8.
5. Kode di `src/`, `database/`, dan `pom.xml` harus bersih tanpa komentar.
